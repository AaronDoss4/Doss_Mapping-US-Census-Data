# Instructions for Rendering

1. Download and unzip the project folder.
2. Open the project folder in RStudio.
3. Open Doss_Mapping_US_Census_Data.qmd.
4. Install the these required R packages if they are not already installed:
install.packages("tidyverse")
install.packages("sf")
5. Make sure va_income.rds is in the same folder as the .qmd file.
6. Click the Render button at the top of RStudio.
7. The completed HTML report will be generated in the project folder.
